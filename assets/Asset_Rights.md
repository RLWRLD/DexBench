# Asset license and attribution guide

The [license statement](ASSET_LIST.md#license) applies CC BY 4.0 to the assets
unless an exception is stated. The [generated index](Asset_Rights_Index.md)
provides package paths, versions, providers, attribution and original-source links.
Retain those credits, the license links, modification notices and the component
texts in [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).

## Maintenance

In the source repository, `python3 scripts/tools/build_asset_rights_index.py`
generates the public index and the separate internal audit report. `--check`
checks both. Generation requires the internal review inputs; a standalone asset
checkout contains the published credits and does not need those inputs.
